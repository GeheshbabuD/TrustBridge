# TrustBridge Backend Instructions

Use JavaScript ES modules, Express, PostgreSQL, Prisma, JWT, bcrypt and Zod. Follow MVC plus services: models persist; controllers translate HTTP; routes define endpoints; services own business rules; middleware handles auth, roles, validation, rate limits and errors; config validates environment/providers; utils are reusable helpers. Keep controllers thin. Use integer minor units plus currency, explicit transaction states, DB transactions/concurrency controls, immutable ledger entries, idempotency and reconciliation. Internal ledger is not legal custody. AI is advisory and cannot release/refund money or decide disputes. Keep PII and evidence off-chain.

At each future implementation session read this file, docs/BACKEND_BLUEPRINT.md, DEVELOPMENT_LOG.md, PROGRESS_REPORT.md and relevant designs. Verify code/tests and reconcile status. Work dependency-ready task IDs. Mark IN PROGRESS before implementation; add/run required tests, review security and acceptance criteria; sync tracker/log/report. Mark complete only with code and passing evidence. Never fabricate results. Avoid empty placeholders, duplicate installs, migrations against unknown DBs, real money, deployment or commits without scoped task. No TypeScript application code.
